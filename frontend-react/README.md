# React Portfolio Frontend

Portfolio web application built with React 19, TypeScript, Vite, Tailwind CSS v4, and shadcn/ui.

Includes a portfolio landing page, resume viewer, Pokemon Explorer with search/pagination/CSV export, and cookie-based JWT authentication.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Test

```bash
npm run test
```

## Deploy

Configured for Vercel deployment — see `vercel.json`.
