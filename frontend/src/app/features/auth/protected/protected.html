How it works

  1. Sign-in: the NestJS API (Fastify) validates the request with Zod and sets a JWT in an HttpOnly cookie, so the token never reaches JavaScript.
  2. Session restore: when you open a protected page without a session in memory, the guard calls /auth/me; the cookie is sent automatically with withCredentials. Public pages never wait for the API.
  3. Route protection: the functional authGuard checks the signal store first and redirects anonymous users to the sign-in page.
  4. Logout: the API expires the cookie and the client store is reset.

Demo only: users are kept in memory and disappear when the serverless instance restarts.
